# AI-Lead-Qualification-CRM
An automated lead processing and CRM workflow built in Make.com. Triggers on new Google Forms responses, analyzes inquiries using OpenAI (GPT-5 nano) for scoring (1–10) and intent, routes leads via conditional filters to Slack or specific Google Sheets tabs (CRM_Leads, Lead_Archive, Lead_Log), and includes robust error-handling fallback logic.
